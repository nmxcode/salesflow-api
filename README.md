# SalesFlow API

A professional RESTful API for customer management built with FastAPI and PostgreSQL.

## Tech Stack
- FastAPI
- PostgreSQL
- SQLAlchemy
- Pydantic

## Features
- Full CRUD operations for customers
- Pagination and search
- Input validation
- API documentation with Swagger UI
